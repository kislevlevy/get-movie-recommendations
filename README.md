# Get Movie Recommendations

## Project Overview

"Get Movie Recommendations" is a powerful and efficient movie search engine that allows users to search by name, year, and type (movie/TV). It offers a quick and responsive experience with a clean design. A detailed modal provides more information on each movie.

## Features

- Search by movie name, year, and type (movie/TV)
- Quick response time with real-time search results
- Clean and modern user interface with detailed movie modals

## Technologies and Tools

- **HTML:** Structure of the web page
- **CSS:** Styling of the web page
- **JavaScript:** Logic and interactivity
- **OMDB API:** Data source for movie information
- **JSON:** Data format for API responses

## Skills Demonstrated

- **API integration:** Fetching and displaying data from the OMDB API
- **DOM manipulation:** Dynamically updating the content and style of the web page based on user interactions
- **Responsive design:** Ensuring the application works well on various devices and screen sizes

## Installation

To run the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/kislevlevy/get-movie-recommendations
   ```
2. Navigate to the project directory:
   ```bash
   cd get-movie-recommendations
   ```
3. Open `index.html` in your preferred web browser.

> You can also preview the application by visiting the following link: [Get Movie Recommendations](http://kislev.me/get_movie_recommendations)

## How to Use

- Enter a movie name, year, or type (movie/TV) in the search bar.
- View real-time search results as you type.
- Click on a movie to view detailed information in a modal.
